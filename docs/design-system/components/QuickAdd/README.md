# QuickAdd

Registo rápido de transações no iPhone: bottom sheet a altura total com teclado numérico próprio.

- Objetivo: valor → categoria → Guardar em menos de 5 segundos. Conta (última usada) e data (hoje) vêm preenchidas.
- O valor é o elemento maior do ecrã, em `amount` a 52px, com cursor `lake`.
- Teclado próprio para garantir vírgula decimal e milhares em es-AR, sem depender do teclado do sistema.
- Categorias como chips: as 4 mais usadas + "Mais…". Sem ícones.
- O botão diz o que vai acontecer ("Guardar despesa"), muda com o tipo.
- No desktop o mesmo formulário abre como sheet lateral de 440px (atalho N).
