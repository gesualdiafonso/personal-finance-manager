# Money

Como se escrevem valores em ARS no PFM: cinco tamanhos, sinal explícito, centavos atenuados, sempre tabulares.

- Formato es-AR: `$ 4.812.340,56`. Menos tipográfico (U+2212) para negativos; `+` para receitas.
- Herói em Instrument Serif; todos os outros em Instrument Sans 500 com `font-variant-numeric: tabular-nums lining-nums`.
- Receitas e despesas em `ink`. `alert-text` só para valores que exigem ação (vencidos, acima do orçamento).
- Totais por baixo de uma régua dupla, como num balanço.
