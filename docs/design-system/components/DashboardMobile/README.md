# DashboardMobile

Início no iPhone (390pt): a mesma ordem de leitura do desktop, recomposta para uma coluna e para o polegar.

- Herói a 52px (`display-hero-mobile`); a barra das contas substitui a legenda (toca para ver detalhe).
- Os indicadores de obrigações ficam lado a lado numa faixa de duas colunas: é o único par que cabe sem abreviar.
- "A vencer" mostra três itens + "Ver todas". Swipe para a esquerda → "Paga".
- Evolução e categorias partilham um bloco com tabs sublinhadas: um gráfico de cada vez.
- O orçamento mostra só as três categorias mais em risco.
- Tab bar: Início · Transações · + · Obrigações · Mais. O + abre o QuickAdd.
