# Controls

Botões, chips, badges e campos: a base shadcn/ui com os tokens do PFM aplicados.

- Quatro variantes de botão: primary (`forest`), secondary (borda `line-strong`), ghost e destructive (`alert`). Um só primary por ecrã.
- Altura 36px no desktop, 44px no mobile; `radius-sm`.
- Foco: anel de 2px em `lake`, sempre visível com teclado.
- Labels de campo em `label` por cima do input; ajuda em `body-sm` `ink-2`; erro em `alert-text` com a instrução para corrigir.
- Inputs de valor alinham à direita e usam tabular-nums.
- Badges: ponto + texto, nunca só cor.
